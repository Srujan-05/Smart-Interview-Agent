DATABASE SCHEMA
===============

users
  - id (UUID, PK)
  - email (String, unique)
  - name (String)
  - phone (String, nullable)
  - location (String, nullable)
  - password_hash (String, bcrypt)
  - created_at (DateTime)

profiles
  - user_id (UUID, FK, unique)
  - skills (JSON)
  - experience (JSON)
  - projects (JSON)
  - education (JSON)
  - seniority_level (String)
  - domain_exposure (JSON)
  - training_profile (JSON)
  - resume_filename (String, nullable)
  - resume_path (String, nullable)

interview_sessions
  - id (UUID, PK)
  - user_id (UUID, FK)
  - mode (String) [Behavioral/Technical/Mixed/Mock]
  - difficulty (String) [Easy/Medium/Hard/Adaptive]
  - job_id (String, nullable)
  - questions (JSON)
  - answers (JSON)
  - session_metrics (JSON)
  - started_at (DateTime)
  - ended_at (DateTime, nullable)
  - status (String) [active/completed]

feedback_reports
  - id (UUID, PK)
  - session_id (UUID, FK, unique)
  - overall_score (Float)
  - breakdown (JSON)
  - per_question_feedback (JSON)
  - recommendations (JSON)
  - created_at (DateTime)


API ENDPOINTS (11 total)
========================

Authentication (2)
  POST   /api/auth/login                  → LoginResponse
  POST   /api/auth/register               → LoginResponse

Profile (2)
  GET    /api/profile                     → UserProfile
  PUT    /api/profile                     → UserProfile

Resume (2)
  POST   /api/resume/upload               → {"message": "..."}
  POST   /api/resume/parse                → {"message": "..."}

Jobs (1)
  GET    /api/jobs?query=...&location=... → Job[]

Interview (3)
  POST   /api/interview/start             → InterviewSession
  POST   /api/interview/submit-answer     → {"message": "..."}
  POST   /api/interview/get-feedback      → FeedbackReport
  GET    /api/interview/sessions          → SessionSummary[]

WebSocket (1)
  WS     /ws/interview?sessionId=X        ↔ SessionMetrics
